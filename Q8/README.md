# Q8 - Student CRUD using Sequelize
Express + Sequelize + React

## Features
- Add Student
- List Students
- Edit Student
- Delete Student
- Sequelize ORM
- SQLite database (no separate MySQL setup needed)
- Basic CSS

## Run Backend
cd backend
npm install
npm start

Backend: http://localhost:5000

## Run Frontend
Open another terminal:
cd frontend
npm install
npm run dev

Frontend: http://localhost:5173

The SQLite database file `students.sqlite` is created automatically.
